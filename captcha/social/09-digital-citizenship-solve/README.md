# 📱 디지털 시민성 문제 해결

개인정보 보호·사이버 예절·가짜뉴스·온라인 책임 같은 현대 온라인 사회문제를 다루는 캡챠입니다.

- **DB 문제 타입**: `DIGITAL_CITIZENSHIP_SOLVE`
- **API**: `/api/digital-citizenship`  ·  **포트**: `4809`
- **구성**: 5단계 × 5문제 = 25문제 (단계별 4개 이상 정답 시 통과)

## 5단계
1. 온라인 문제 상황 찾기 — 하면 안 되는 온라인 행동 모두 담기 (담기·드래그)
2. 개인정보 보호 — 공개하면 안 되는 정보 모두 담기 (담기·드래그)
3. 사이버 예절 분류 — 좋은 댓글 / 나쁜 댓글 분류 (분류·드래그)
4. 가짜뉴스 구분 — 믿을 수 있는 / 의심스러운 정보 분류 (분류·드래그)
5. 대처 순서 배열 — 사이버폭력·온라인 문제 대처 순서 (순서·드래그)

## 실행
```bash
cd ../..            # capcha.social
npm run start:09
# → http://localhost:4809
```
DB 비밀번호는 이 폴더에 `.env`(→ `.env.example` 복사)로 넣습니다. 없으면 메모리 폴백으로 동작합니다.

자세한 API 사용법은 상위 [../../API_GUIDE.md](../../API_GUIDE.md) 참고.
