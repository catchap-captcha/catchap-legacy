# 🫀 심폐소생술·자동심장충격기 안전 순서

응급처치 이론과 순서를 배우는 캡챠입니다. 1~3단계는 이론/금지 행동 선택, 4~5단계는 실제 안내 사진 카드 순서 맞추기입니다.

- **DB 문제 타입**: `CPR_AED_SAFETY_SEQUENCE`
- **API**: `/api/cpr-aed`  ·  **포트**: `4810`
- **구성**: 5단계 × 5문제 = 25문제 (단계별 4개 이상 정답 시 통과)

## 5단계
1. 금지 행동 찾기 — 하면 안 되는 행동 고르기 (선택형)
2. 심폐소생술 기본 이론 — 올바른 설명 고르기 (선택형)
3. 자동심장충격기 안전 이론 — 안전 수칙 고르기 (선택형)
4. 심폐소생술 사진 5장 순서 맞추기 (사진 드래그)
5. 심폐소생술 5장 + AED 4장 전체 순서 맞추기 (사진 드래그)

> 🖼️ 4~5단계 사진은 `frontend/assets/cpr/*.png`, `frontend/assets/aed/*.png` (올려주신 안내 사진). 카드의 "크게" 버튼으로 확대해 볼 수 있습니다.

> ⚠️ 교육용 자료입니다. 실제 응급 상황에서는 즉시 119에 신고하고, 주변 어른 또는 구급대원의 안내를 따르세요.
