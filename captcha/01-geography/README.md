# ① 지리 영역 CAPTCHA 🐱🗺️ (선 연결형)

4학년 사회 **지리 영역** [4사05·09·10]. 지도 기호·지도 요소·자연/인문환경·촌락/도시 개념을
**선으로 연결**하는 캡챠. **5단계 × 5문제 = 총 25문제.** 1단계부터 난이도 상승.

| 단계 | 내용 |
| --- | --- |
| 1 | 지도 기호 1개 ↔ 장소 (보기 2개) |
| 2 | 2쌍 연결 (보기 3개, 방해 1) |
| 3 | 지도 요소 3쌍 (딱 맞는 보기 3개) |
| 4 | 3쌍 연결 (보기 4개, 방해 1) |
| 5 | 자연·인문환경·촌락·도시 4쌍 (보기 5개, 방해 1) |

## 실행
```bash
cp .env.example .env      # DB_PASSWORD 입력
npm install
npm start                 # → http://localhost:5510
```
API `/api/geography` · DB `catchap_quiz` · 테이블 `geo_session` / `geo_attempt` · DB 없이 메모리 폴백.
